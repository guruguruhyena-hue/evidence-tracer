Privacy / データの扱い

入力したウォレットや検索結果は、Evidence Tracerの独自サーバーには保存しません。照会時には各ブロックチェーンAPIへリクエストします。

Trace結果はこのブラウザに保存・復元できます。

APIキー・秘密鍵・シードフレーズは保存しません。

01 · Wallet Trace / ウォレット照合

まず公開ウォレットを選び、指定した送金先への送金履歴を照会します。一度照会した結果は下の「Saved Trace Cache」で再利用できます。

非公開の照合先アドレス（ブラウザ内のみ）

送り先アドレスをチェーン名とともに入力すると、そのアドレス宛ての送金だけを照合します。共有の初期設定には、他の利用者の事件情報は含まれていません。

登録された照合先はありません。

EVM選択時のみ使用します。BaseのPDF TxID逆引きにはEtherscan APIではなくBase公式RPCを使用します。

EtherscanのAPI Keysページを開きます。APIキーはこのブラウザのメモリ上で検索時のみ使用します。照会リクエストはEtherscanへ送信されます。

Solana公開RPCで403 / 429が出る場合は、Helius / QuickNode等の専用RPC URLを入力してください。秘密鍵は不要です。

04 · Deposit Reconciliation / 入金照合

入金記録（PDF / CSV / JSON）を読み込みます。

保存済みTraceや現在のセッションの送金記録と照合します。

ファイル内容はEvidence Tracerのサーバーにアップロードされません。

操作順序
① PDFを選択② Reconcile③ SOL / Base TxID照会（任意）④ JSON出力

PDF：履歴からページ番号・抽出原文・PDF SHA-256を保持します。

CSV / JSON：推奨列は date/time または timestamp、asset、amount、txid（任意）、id（任意）です。

照合：TxIDに加え、送金先・資産・金額なども比較します。

SOL source resolution not run. Shared public RPCs may block requests (403/429); use Custom RPC URL with archive history if needed.

Base source resolution not run. Uses the official Base Mainnet RPC; no Etherscan paid plan required.
