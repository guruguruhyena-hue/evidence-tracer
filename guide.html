EVIDENCE TRACER · IZAKA-YA USER GUIDE

取引履歴から入金の証拠を整理する
かんたん操作マニュアル

IZAKA-YAの利用者が、自分の取引履歴PDFをもとに、CSV変換・参考円評価・ウォレットの送金記録・入金照合まで進めるための1ページ案内です。専門知識がなくても、各ステップのリンクから操作できます。

ウォレット照合PDF/CSV変換統合資金照合円時価評価証拠資料GitHub（公開コード）
費用不要の公開ツール。秘密鍵・シードフレーズは絶対に入力しません。
はじめに：自分のウォレット公開アドレス、IZAKA-YAの各履歴PDF、取引所の出金明細、受取側の記録を準備してください。原本は変更せず保管してください。照合できなかった行を「送金なし」と断定しないでください。
まず全体の流れを確認
📥① PDF保存サイトから履歴保存
📄② CSV変換列順・種別を統一
🧮③ 数量と円評価入金・交換・運用
🔎④ ウォレット照合送金先・TxID確認
🔗⑤ 入金照合PDFとチェーン照合
🗂️⑥ 証拠を保存JSON・CSV・PDF

6つの操作ステップ

1

IZAKA-YAの履歴PDFを保存

サービスの入金・出金・交換・融資履歴をそれぞれ開き、印刷画面から「PDFとして保存」。取引所の出金明細や確認メールも別に保管します。

※PDFのファイル名が「出金」でも本文が「入金」の場合があります。必ず本文を確認。

2

PDF → CSVに変換

「履歴A」にPDFを選択。抽出件数、日付、数量、TxID、元ページを確認し、必要ならCSV列順を変えて保存。別の履歴は「履歴B」に読み込めます。

PDF・CSV変換を開く →

画像だけのPDFはOCRが必要。読めない行を自動で補わないでください。

3

履歴を統合・参考円評価

統合照合画面へ入金・交換・融資・出金の各資料を入力。通貨別数量を比較します。入金の「参考円評価額」は円時価評価画面で別に算出します。

統合資金照合 → 円時価評価 →

※内部交換・貸付元本・利息・手数料を入金として重複計上しないこと。

4

自分のウォレットを照合

自分が管理する送金元の公開ウォレットアドレスを入力し、対応チェーン・送金先を指定。「Scan & Match selected destinations」で検索します。

ウォレット照合を開く →

APIの制限や履歴の取得範囲に注意。秘密鍵・リカバリーフレーズは不要です。

5

入金履歴とチェーン記録を突合

同じ画面の「04 · Deposit Reconciliation」へ入金PDF / CSVを追加し、「Reconcile imported records」を実行。TxID・通貨・数量・送金先・日時を比較します。

入金照合画面へ →

SOL / BaseはTxID照会も可能。照合成功でも運営者の管理権・契約上の債務まで証明しません。

6

証拠一式を保存・提出に備える

Export JSON / CSV、Print / Save PDFで結果を保存。日時・TxID・出典・PDF原本のSHA-256を確認し、警察提出用の説明と証拠番号を付けます。

警察提出用の整理画面 →

結果を公開SNSやGitHubにアップする場合、個人アドレス・連絡先等の公開範囲に注意。

照合結果の読み方

✅ 一致した記録対象のTxIDや数量などが照合できた範囲。元のチェーン上の取引結果も確認。
⚠️ 要確認 / 未照合記録不足・日時差・API失敗等。未送金や不正が証明されたわけではありません。
📩 サービスの「送金済」IZAKA-YAの画面上の表示。本人ウォレットへの実着金確認とは別です。

提出前のセルフチェック

Evidence Tracerは証拠整理の補助ツールです。PDF・CSVは原則としてブラウザ内で解析し、独自サーバーへアップロードしません。ウォレット照会時は公開ブロックチェーンAPIへ指定アドレス等が送信される場合があります。原本の真正性、サービスの運営主体、確定損害額、犯罪の成立は自動判定できません。
