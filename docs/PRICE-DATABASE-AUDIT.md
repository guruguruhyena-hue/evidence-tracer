## 2. データ出典および計算方式

- **暗号資産価格ソース**: Binance Spot Public Market Data API (`https://data-api.binance.vision/api/v3/klines`, `interval=1d`, UTC 日次終値)
  - 対象ペア: `BTCUSDT`, `ETHUSDT`, `SOLUSDT`, `XRPUSDT`, `USDCUSDT`, `SHIBUSDT`, `OPUSDT`
- **為替レートソース**: Frankfurter v1 Historical Reference Rate (`https://api.frankfurter.dev/v1/2024-12-22..2026-11-23?base=USD&symbols=JPY`)
  - 週末・祝日で為替公表がない日は、対象日以前で最大 7 暦日以内の直近公表日レートを参照し、`evidence_ref` に為替参照日（`FX YYYY-MM-DD`）を明記。
- **計算方式**:
  - BTC / ETH / SOL / XRP / USDC / SHIB / OP: `ASSET/USDT 日次終値 × USD/JPY 参考為替`（小数点以下12桁 `ROUND_HALF_UP`、`method = USDT_PAIR_DAILY_CLOSE_X_USDJPY_REFERENCE`）
  - USDT: `1 × USD/JPY 参考為替`（`1 USDT = 1 USD` 仮定、`method = USDT_USD_PARITY_ASSUMPTION_X_USDJPY_REFERENCE`）
- **留意事項**: 本データは実際の JPY 建て約定価格ではなく**参考円換算額**であり、実データ応答のハッシュを取得していないため `source_sha256` はすべて空欄（`""`）としている。
