取引ハッシュから実際の送信元を調べる（Ethereum / Base / Optimism）

01 · 検証対象を入力

TxIDをブラウザから直接Blockscoutへ照会します。本人の事件情報は初期登録されていません。

公開RPCにアクセスできない場合のみ入力してください。HTTPS URLを使用します。APIキー付きURLは共有・公開しないでください。

TxIDを入力してください。

Optimismで取得できないときは、OP Mainnet公式エクスプローラー でTxIDを直接検索できます。取得不可は取引不存在の証明ではありません。

外部APIへ送るのは入力したTxIDとチェーンIDです。IPアドレスなどのアクセス情報がAPI事業者に記録される場合があります。ウォレットの秘密鍵は不要です。

02 · Transaction Details / 実行元

照会前です。

03 · ERC-20 Token Transfers / 実際のトークン移動

Transaction Fromと、Token Transfer Fromは同一とは限りません。RPC経由の数量はトークンdecimals未取得のraw整数単位で表示されます。対象の資産・数量・受取先が一致するか、必ず確認してください。
